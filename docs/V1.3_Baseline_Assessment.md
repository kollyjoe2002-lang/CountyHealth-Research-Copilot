The exact code generalization map, query contracts, allowed combinations,
coverage denominators, semantics and staged implementation gates are in

warehouse: actual sex/age/race cross-product availability; unique analytical

self-contained validators. Full legacy integration remains gated on a fresh
warehouse/API run. No existing analytical behavior should be replaced until
that gate is green. Phase 2 was not started in this checkpoint.
